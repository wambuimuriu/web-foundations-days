About QuickNotes

QuickNotes is a simple app for writing down short notes so you never forget an idea. It keeps everything in one place, where you can add and read your notes at any time.

How to use QuickNotes

  1. Open the Home page.
  2. Type your note into the text box.
  3. Click the Add Note button, or press Enter.
  4. Read your notes in the Your notes list.

Features

  • Add a note in seconds
  • See all your notes in one list
  • Simple, distraction-free page
  • Works on phones and computers

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
